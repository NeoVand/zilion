**Status: full baseline of the 0.3 Z80 core** (`compat: '0.3'`, variant `classic`, generated with the io hooks so that
the vector ports reach it). All 1,604 SingleStepTests/z80 `v1` files ran (1,604,000 tests, data pinned at commit
`ebe1875d48f374bcfd4b505d8eb8ee751568b5f7`), plus the 384 analytic wasted-prefix vectors (`test/vectors/z80/analytic`)
and the 86 hand-derived R and WZ probes (`test/vectors/z80/analytic/probes`, `tools/z80-probe-vectors.py`). The rules
file is selected by the core's SHA-256 (`core_sha256` in `test/vectors/z80/expected-0.3.0.json`).

### Findings

1. **Unexpected divergences: none**, over 1,604,470 tests, with three rules, each for something deliberately not
   modelled:
   - **Q** (1,156,022 tests): the Q latch is Zilog-NMOS-specific; `classic` does not model it and the harness passes
     the field through. Variant `zilog-nmos` models it (its own baseline: no Q divergence at all).
   - **Q-XY** (2,210 tests in 6 files): SCF/CCF X/Y from A only, where an NMOS Z80 uses ((Q xor F) or A). The rule is
     model-checked: it explains a test only if the vector follows the NMOS formula and Zilion the A-only formula.
   - **EI-P** (1,203,721 tests): the EI-delay and LD A,I/R interrupt latches. Zilion has no interrupts.
2. **Everything the 0.2.0 ledger needed eleven other rules for now matches**, field for field:
   - WZ (MEMPTR): the 767,839 tests in 786 files where 0.2.0 diverged, and the 86 probes (16-bit wraps, the
     low-byte-only increments, JP cc/CALL cc not taken, IN C,(C), every block form);
   - BIT n,(HL) X/Y from WZ (5,983 tests); R after a wasted prefix (384 tests); IM 0/1/2 and the mirrors (5,299
     tests; ED 4E and 6E select IM 0 in the vectors);
   - block-repeat flags: repeating LDIR/LDDR/CPIR/CPDR X/Y from PC bits 13/11 (2,959 tests diverged in 0.2.0), and
     INIR/INDR/OTIR/OTDR X/Y, H and P/V (3,601 tests);
   - ports: all 30 I/O files through the vector's port lists (`IN A,(n)` on port `(A << 8) | n`, INI/IND on BC
     before B is decremented, OUTI/OUTD after, `OUT (C),r` and `OUT (C),0`).
3. **WZ of the repeating block I/O forms.** The design left INIR/INDR/OTIR/OTDR open ("repeat case to be verified
   against vectors"). The vectors settle it: a repeating block instruction of any kind sets WZ = PC + 1 (the address
   of its second byte), in every one of the 3,990 repeating INxR/OTxR tests; the finishing iteration sets WZ as the
   single form does (BC ± 1).
4. **Coverage note.** SingleStepTests' random BC and B make almost every block-repeat test a repeating one: of 1,000
   tests per file, 0 to 5 are the finishing iteration (none for LDIR, LDDR, CPDR and OTDR). The finishing iteration
   runs the single form's code (LDI, CPI, INI, OUTI …), which has its own 1,000 tests per file, and the probes include
   a finishing LDIR and a CPIR stopping on a match.
5. **The harness can still fail.** The self-test plants 24 mutants, among them the 0.2 behaviour of every fix (wasted
   prefix counted twice, BIT X/Y from the operand, WZ off by one, WZ only when JP cc is taken, no WZ for (IX+d),
   IM ignored, repeat X/Y from the data, INxR/OTxR P/V not adjusted, `IN A,(n)` on port n, a silent `OUT (C),r`).
   Each produces unexpected divergences. Against the 86 probes, the compat 0.2 core fails 73.

### What changes for an Algocell soup (compat '0.3' against '0.2')

A soup has no I/O device and no interrupts; with its hooks off the 0.3 core still reads 0 on IN. What can differ:

- **X/Y bits of F**: after BIT n,(HL) (now from WZ), and after a repeating block iteration whose flags survive (the
  budget ends mid-repeat, or the instruction overwrites its own bytes: self-copying code). They reach memory only
  through `PUSH AF` (or `EX AF,AF'` and a push); no conditional tests X/Y.
- **R** after a wasted prefix (one less per wasted prefix), visible through `LD A,R`.
- **A lane halted by the host** stays frozen (R no longer counts on); the world's run loop never steps it, so world
  outputs do not change.

On the 600,000 random programs of the compat test (100,000 at each P = 32, 38, 40, 64, 100, 128; Algocell's pair
world, 128 steps), 0.355–0.614% of lanes end with a different state record, almost all in F (and R) only; the final
memory differs in 1–3 lanes per 100,000. This is a measurement on random programs, not the pre-registered impact
study (design §5.7), which runs on the archived soups.

### Determinism

The plain run and a run with `--repeat 2` (every dispatch twice, byte-compared) gave the same ledger SHA-256.
